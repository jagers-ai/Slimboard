# 사진 글자 미리보기

로그인한 홈이 보이면 한글 OCR 준비를 시작한다. 브라우저에서 데이터 절약을
켜면 사진 메뉴나 선택 단계에서 시작한다. AI로 변환을 누르면 브라우저에서
읽힌 글자를 먼저 보여준다. 신뢰도 기준을 넘지 못한 줄은 `___`로
표시하고 모든 줄을 읽지 못했으면 미리보기를 열지 않는다. 미리보기는
검토용이며 저장하지 않는다. 기존 서버가 사진으로 분석한 원문과 요약이
최종 노트에 들어간다. 브라우저 OCR이 실패하거나 지원되지 않는 경우에도
서버 분석과 저장은 그대로 진행한다.

빌드에서는 PaddleOCR.js 0.4.2의 Worker, ONNX Runtime Web 1.24.3,
PP-OCRv5 모바일 탐지 및 한글 인식 모델을 준비한다. 모델 내용은 해시로
검증하고 gzip으로 묶는다. 브라우저는 WASM 전용 실행 파일과 두 모델을
동시에 내려받는다. 각 파일을 푼 뒤 Worker가 브라우저 메모리에서 읽는다.
로그인한 홈의 HTML에 내려받을 파일을 표시해 앱 코드가 준비되는 동안
브라우저가 받기 시작할 수 있게 한다. Worker는 모델이 도착하는 동안
이미지 처리에 쓰는 OpenCV 실행 환경을 미리 준비한다.
브라우저는 Slimboard와 같은 주소에서만 실행 파일과 모델을
받는다. 빠른 미리보기 단계에서 사진이 모델 배포처로 전송되지 않는다.
모델 파일은 생성물이므로 Git에는 넣지 않는다. 배포 자산에 포함되며,
각 라이선스는 [third-party-ocr](third-party-ocr/)에 보관한다.

2026-11-18 한글 손글씨 1장의 기준 원문(한글 37자)을 사람 눈으로 확인했다.
같은 PNG, Standard, original 이미지 상세도, 원문만 출력하는 지시로 각
조합을 1회 실행했다. 시간은 Mac에서 API 요청을 보낸 때부터 재며
노트 업로드, 저장, 브라우저 렌더링 등 웹앱 전체 시간은 포함하지 않는다.

| 모델 | 추론 | 첫 글자 | 원문 완료 | 사용 토큰 | 한글 일치 |
| --- | --- | ---: | ---: | ---: | ---: |
| GPT-6.1 Sol | medium | 5.311초 | 5.594초 | 622 | 37/37 |
| GPT-6.1 Sol | low | 5.036초 | 5.410초 | 551 | 37/37 |
| GPT-6.1 Terra | high | 8.989초 | 9.359초 | 860 | 37/37 |
| GPT-6.1 Terra | medium | 6.970초 | 7.309초 | 659 | 37/37 |
| GPT-6.1 Terra | low | 4.217초 | 4.620초 | 542 | 37/37 |

Sol low의 괄호 모양만 다른 표기를 썼다. 이 사진에서 다섯 API 조합 모두
첫 글자까지 2초를 넘었다. 브라우저 OCR의 단독 인식은 준비 후 284~305ms였으나
첫 두 줄에서 한글을 틀렸으므로 높은 신뢰도의 줄만 먼저 보여준다.
실제 앱 화면의 측정 범위와 제한은 [모바일 확인](mobile-testing.md)에 있다.
